# License and attribution notes

This repository starts as a documentation scaffold. No license is assigned here to future kernel patches or imported source files.

Before adding code:
- Check the license of the exact upstream repository and files.
- Preserve copyright and license headers.
- Keep KernelSU Next source and derivative changes under the license required by that project.
- Keep Linux kernel-derived code under its applicable GPL-2.0 terms.
- Do not copy an entire upstream kernel tree without a deliberate, license-compliant decision.
- Add a top-level LICENSE only after deciding the intended licensing scope for original project-authored material.

Documentation and code may have different licensing requirements.
